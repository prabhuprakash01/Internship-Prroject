# Semantic HTML5 Portfolio

A responsive, four-page personal portfolio starter:
- `index.html` — home
- `about.html` — about and skills
- `projects.html` — project examples
- `contact.html` — keyboard-accessible contact form
- `styles.css` and `script.js` — shared styling and small enhancements

## Run locally
Open `index.html` in a browser, or use a local development server.

## Customize before publishing
1. Replace “Alex Morgan” and the sample biography/projects with your own details.
2. Replace `https://example.com/...` canonical URLs with your real domain.
3. Connect the contact form to a secure form handler or backend. The current form is a front-end demo and does not send email.
4. Add real project links and a suitable social preview image if desired.

## Accessibility features
Semantic `header`, `nav`, `main`, `section`, `article`, and `footer` landmarks; one page-level `h1`; skip link; descriptive navigation label; visible keyboard focus; properly associated form labels; native required/email validation; live status region; responsive layout; and reduced-motion support.

A perfect Lighthouse score cannot be guaranteed from source code alone. Scores depend on the deployed environment, browser, network, and audit version. Run Lighthouse after replacing the sample content and deploying the site.
